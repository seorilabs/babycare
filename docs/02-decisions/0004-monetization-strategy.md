# ADR 0004: 수익화(BM) 전략

## Status

Implemented — 2026-08-08

## Context

- 베이비 트래커 시장은 무료·저가 대안이 포화 상태다. "기록(logging)"은 커머디티라 일반 프리미엄 구독에 대한 지불의사가 낮다. 성공 사례(Huckleberry, Glow)도 로깅이 아니라 인사이트·코칭 등 차별화 레이어로 과금한다.
- 함께봄은 **프라이버시 우선·무추적** 포지셔닝(개인정보방침에 광고·추적 미사용 명시 가능)과 **초대 기반 공동 기록 = 바이럴 성장 엔진**이라는 두 성격을 가진다. 공유 기능 유료화는 성장을 죽이고, 개인화 광고는 무추적 포지셔닝과 충돌한다.
- 운영비는 구조적으로 낮다: 작은 Firestore 문서, 미디어 없음(Storage≈0), bounded timeline 읽기(pageSize 20 / maxCachedEvents 200), Functions scale-to-zero. 소규모는 Blaze 무료 쿼터 내, 수천 팀 규모여도 월 수십 달러 수준. 즉 무료 운영이 지속 가능하다.
- 앱은 아직 미출시(익명 인증만, 실계정·계정삭제·2기기 QA·deployment approval 미완). 개인정보방침·스토어 라벨은 모두 제출 전 초안이라 광고 유무 문구 변경은 편집 한 번이면 된다.

## Decision

단계적 수익화 원칙은 유지하되, 2026-08-08 론칭 준비 지시에 따라 v1.x의 최소 광고를 첫 공개 후보에 포함한다.

1. **첫 공개 후보**: 무료 · 무구독. 통계 요약과 기록 기능은 무료·무광고로 유지한다.
2. 보상형(리워드) 광고 **딱 1개**를 **통계 상세** 화면에 배치한다.
   - **옵트인 리워드** 포맷(강제 전면 아님), **비개인화** 광고(추적·ATT 없음).
   - unlock 지속: **24시간**. 기록 루프(수유·기저귀·수면)는 **무광고 유지**.
3. **v2 (데이터 축적 후)**: unlock 보상을 **또래 비교 인사이트**(같은 월령 밴드 익명 집계 벤치마크)로 격상. 이것이 진짜 차별점이자 데이터 해자.

광고 모델(배너/개인화/강제 전면)과 소비자 대상 일반 프리미엄 구독은 채택하지 않는다.

## Consequences

- 모바일은 AdMob + UMP 비개인화 리워드, AppsInToss는 통합 리워드 광고를 사용한다. 운영 광고 ID·UMP 메시지·실기기 광고 완료 QA 전에는 공개 후보로 보지 않는다.
- 광고 요청·노출·보상은 GA4와 Platform Events 양쪽에 기록한다. 통계 상세는 보상 완료 시각부터 기기별 24시간 열린다.
- **또래 비교(v2) 전제**:
  - 데이터 볼륨 — cohort(월령 밴드)당 최소 N명 이상일 때만 표시(k-익명).
  - **비의료 프레이밍** — "참고용 커뮤니티 평균, 의학적 판단·정상 여부 아님". 퍼센타일·건강 경고처럼 보이면 비의료 포지셔닝·스토어 건강 정책 리스크.
  - **프라이버시 설계** — 타 사용자 원본 조회가 아니라 백엔드 집계 job이 익명 집계 문서만 생성, 클라이언트는 그것만 read. 개인정보방침에 "익명 집계 벤치마크" 고지 추가.
- **비용 가드레일**: GCP 예산 알림 설정됨(seorilabs-babycare, 월 ₩20,000, 50/90/100%). 확장 전 App Check 활성화 권장(남용성 비용·백엔드 보호).
- **출시 blocker**: AdMob 앱/광고 단위 ID, AppsInToss 광고 그룹 ID, UMP 메시지, GA4 relay secret/measurement ID, 마켓 개인정보 답변, 세 타깃 실기기 광고 QA.
