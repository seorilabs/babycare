# ADR 0006 — 복약 기록의 안전 경계

- 상태: Accepted
- 결정일: 2026-08-10
- 적용 범위: Android, iOS, AppsInToss의 체온·복약 기록

## 맥락

사용자는 아세트아미노펜·이부프로펜·항생제와 직접 정의한 약의 실제 복약 시각을 공동 양육자와 공유하고, 같은 성분의 간격을 놓치지 않기를 원한다. 그러나 영유아 약의 적정 용량과 사용 가능 연령은 체중, 나이, 제품 농도, 처방에 따라 달라지므로 기록 앱이 이를 계산하거나 처방하면 안 된다.

공식 근거는 다음과 같다.

- 미국소아과학회는 아세트아미노펜을 제품 라벨과 의료진 안내에 따라 사용하고, 12세 미만의 일반 안내에서 4시간 간격을 제시한다. 2세 미만은 의료진 안내 없이 투여하지 않도록 안내한다: <https://www.healthychildren.org/English/safety-prevention/at-home/medication-safety/Pages/Acetaminophen-for-Fever-and-Pain.aspx>
- 미국소아과학회는 이부프로펜의 일반 간격을 6~8시간으로 안내하고, 6개월 미만은 의료진 지시가 없으면 사용하지 않도록 안내한다: <https://www.healthychildren.org/English/safety-prevention/at-home/medication-safety/Pages/Ibuprofen-for-Fever-and-Pain.aspx>
- FDA는 여러 제품에 같은 아세트아미노펜 성분이 들어갈 수 있으므로 성분 중복과 라벨의 용량·간격·일일 횟수를 확인하도록 안내한다: <https://www.fda.gov/drugs/safe-use-over-counter-pain-relievers-and-fever-reducers/acetaminophen>
- NICE는 두 해열제를 동시에 투여하지 않고, 교차 투여는 불편감이 다음 투여 시각 전에 지속·재발할 때만 고려하도록 안내한다: <https://www.nice.org.uk/guidance/NG143/chapter/recommendations>

## 결정

1. `CareEvent`에 `temperature`와 `medication`을 추가한다.
2. 체온은 섭씨 값과 측정부위를 저장하되 발열 여부를 진단하지 않는다.
3. 복약은 약 이름, 분류, 주성분, 실제 투여량·단위, 실제 시각, 사용자가 제품 라벨 또는 의료진 안내에서 확인한 최소 간격을 저장한다.
4. 아세트아미노펜 4시간, 이부프로펜 6시간은 빠른 입력의 초기값으로만 제공한다. 앱은 용량을 계산·추천하지 않으며 사용자가 이름·용량·간격을 확인하고 수정할 수 있다.
5. 복약 입력 화면에는 2세 미만 아세트아미노펜과 6개월 미만 이부프로펜은 의료진 안내를 먼저 확인하라는 연령 경고를 노출한다.
6. 항생제와 직접 입력 약은 간격을 임의로 채우지 않는다. 사용자가 확인한 값을 반드시 입력한다.
7. 직접 입력한 약은 최근 복약 기록에서 다시 선택할 수 있게 하여 별도 미동기화 프리셋 저장소를 만들지 않는다.
8. 같은 주성분 또는 직접 입력한 같은 약 이름의 최소 간격 안에 새 기록이 있거나, 서로 다른 해열제가 같은 분 단위 시각에 기록되면 경고하고 두 번째 확인 후 저장한다. 실제로 투여된 사고 기록까지 막지 않기 위해 hard block은 사용하지 않는다.
9. 해열제별 다음 가능 시각은 기록에 저장된 사용자 확인 간격으로 계산한다. 이 표시는 투약 지시가 아니라 기록 누락 방지 보조 정보다.
10. 기록 값과 약 이름은 Analytics·Crash log에 보내지 않고 기존 `type` allowlist만 전송한다.

## 결과와 후속 게이트

- 체온·복약은 건강 정보로 취급하고 초대된 그룹 내부에만 저장한다.
- 앱 문구, 개인정보 처리방침, Google Play Data safety, App Store Privacy Labels를 갱신한다.
- 실제 Store/AIT 설치본에서 작은 화면, 큰 글꼴, 오프라인 저장, 두 기기 동기화, 과거 시각, 동일 성분 경고와 최근 직접 입력 프리셋을 QA해야 한다.
- 제품별 농도·체중 기반 용량 계산, 알림, 자동 교차 투여 계획은 이번 범위 밖이며 별도 의료·법률 검토 없이는 추가하지 않는다.
